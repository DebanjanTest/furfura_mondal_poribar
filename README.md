## ✨ Key Features

### 🥁 1. Studio-Grade Dhak Percussion & Loop Engine
- **Procedural Physical Modeling DSP**: procedurally synthesizes authentic Jackfruit (*Kathal*) wood shell resonance (82 Hz bandpass), tapered bamboo (*Kanchi*) stick transients (1850–2400 Hz), high-tension goat-skin harmonics, sacred Conch shell (*Shankha*, 432 Hz), and Bell-Metal Gong (*Kãnsor*).
- **100% Seamless Gapless Continuous Looping**: Built on hardware-clock Web Audio lookahead scheduling (`AudioContext.currentTime`) with **0.000 ms latency**, zero buffering hitch, and zero speech/talk artifacts.
- **Musical Quantized Transitions**: Part-to-part switching seamlessly quantizes to the next musical bar boundary without breaking the rhythm.
- **6 Authentic Puja Sections**:
  1. **রথের বাজনা (Rot / Ratha Yatra Procession)** — 112 BPM (Driving Kaharwa Swing)
  2. **আগমনী ও বরণ বাজনা (Agomoni & Boron Invocation)** — 92 BPM (Ak-kathi Welcoming)
  3. **সন্ধ্যা আরতি ও ধুনুচি নৃত্য (Sandhya Aarti & Dhunuchi Dance)** — 124 BPM (Duk-kathi Syncopated Polyrhythm)
  4. **সন্ধিপূজা ও ১০৮ প্রদীপ মহোৎসব (Sandhi Puja 108 Deepam Climax)** — 128 → 144 BPM (Accelerando Climax)
  5. **বিসর্জন ও বিজয়া শোভাযাত্রা (Bishorjan / Bisarjan Procession)** — 120 BPM (Emotional Immersion Swing)
  6. **এক কাঠি ও দুক কাঠি যুগলবন্দী (Ak-Kathi & Duk-Kathi Master Solo)** — 138 BPM (Virtuoso Solo Roll)
- **Studio Sound Booster & EQ Panel**: Low-shelf Bass Booster (+6dB to +12dB), High-register Stick Snap (+4dB), Dynamic Compressor / Limiter, and Loudness Boost.
- **6 Interactive Drum Pads (Keys `1`–`6`)**: Real-time acoustic trigger pads with golden ripple visual effects.

## 🛠️ Technology Stack

- **Core**: Vanilla HTML5, Modern ES6+ JavaScript, Vanilla CSS with custom tokens.
- **Audio DSP**: Web Audio API (BiquadFilterNodes, DynamicsCompressorNode, GainNodes, PeriodicWave, AudioContext lookahead clock).
- **Visuals**: Canvas API particle physics (Shiuli flowers & ambient embers).
- **Bundler**: Vite 6.
- **Deployment**: Vercel / GitHub Pages.
