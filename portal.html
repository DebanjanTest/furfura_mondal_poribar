৩. ভক্ত ও দর্শনার্থী (Visitor)

বৈশিষ্ট্য: সাইন ইন সম্পূর্ণ ঐচ্ছিক।

ওয়েবসাইট দর্শন, রেডিও ও ঢাক শ্রবণ, স্টোরি কার্ড তৈরি ও শুভেচ্ছা প্রেরণ। ম্যানেজমেন্ট পোর্টালে প্রবেশাধিকার সম্পূর্ণ সংরক্ষিত।

🛠️ Firebase Console-এ নতুন এডিটর যুক্ত করার পদ্ধতি:

  1. Firebase Console-এ গিয়ে mondal-barir-pujo নির্বাচন করুন।
  2. Firestore Database $\rightarrow$ user_roles কালেকশনে যান।
  3. Add Document-এ ক্লিক করে Document ID হিসেবে এডিটরের Google ইমেইল লিখুন (উদা: family_editor@gmail.com)।
  4. Field হিসেবে role = "editor" এবং name = "ব্যক্তির নাম" লিখে Save করুন।
  5. উক্ত ব্যক্তি সাইন ইন করলেই স্বয়ংক্রিয়ভাবে এডিটর ক্ষমতা সক্রিয় হবে!
